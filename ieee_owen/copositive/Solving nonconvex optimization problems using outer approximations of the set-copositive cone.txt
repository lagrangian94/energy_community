Abstract
We consider the solution of nonconvex quadratic optimization problems using an
outer approximation of the set-copositive cone that is iteratively strengthened with
cutting planes and conic constraints. Our methodology utilizes an MILP-based oracle
for a generalization of the copositive cone that considers additional linear equality
constraints. In numerical testing we evaluate our algorithm on a variety of different
nonconvex quadratic problems.

**3 Set-copositivity detection with linear constraints**
 
An outer approximation algorithm based on MILPCOP, as described in the previous
section, uses MILPCOPto check if _S_ ∈COP _n_ +^1 for an iterate _S_ , and if not to

copositive pricing matrix that applies to an underlying problem with discrete variables.

**4 Computational results**
 
In this section we consider applying an algorithm that uses cuts based on an outer
approximation of the set-copositive cone, incorporating additional constraint infor-
mation as described in the previous section. We consider two different classes of
problems: nonconvex continuous quadratic programming instances from the well-
known MINLPLib library, and binary quadratic programming problems. All instances,
possibly after reformulation, have bounded feasible regions, so strong duality holds
between CPOPT and COPOPT by the result of [ 11 ]. All computations in this section,
and the following section, were performed on an Intel(R) Core(TM) i5-9300H CPU
running at 2.40GHz with 16GB RAM. Linear and mixed integer linear problems were
solved via Gurobi 9.1 while nonlinear conic problems were solved via Mosek 9.2. We
used Mosek rather than Gurobi for the solution of conic problems because we found in
preliminary experiments that Mosek was more stable for these problems. Both Gurobi
and Mosek were accessed from Matlab via the YALMIP interface [ 25 ].

**4.1 MINLPLib instances**
 
To begin, we consider problems from MINLPLib corresponding to nonconvex quad-
ratic programming (QP) problems, with only continuous variables. Using the results
from [ 9 ] such problems can be exactly represented in the form CPOPT under mild
assumptions. In order to put problems into the required form for this representation,
all variables must be nonnegative and slacks added to any inequalities to convert them
to equalities. We considered instances where the number of variables after splitting
free variables and/or adding slacks was no more than 70. The optimal values for these
problems are known, having been computed using global optimization software such
as BARON [ 28 ] that relies on spatial branching to refine convex bounds for nonconvex
terms on smaller and smaller domains. By contrast, we are attempting to solve these
problems without the use of spatial branching, instead relying on the constraints that
are generated by MILPCOP(K).
In Table 1 we give the results of applying our outer approximation algorithm to 62
nonconvex QP instances. In the table we give the optimal value for each problem, the
gap between the optimal value and the value for the DNN relaxation of CPOPT (equal
to the value for the SPN restriction of COPOPT), the gap obtained by applying our
outer approximation algorithm using cuts based on MILPCOP(K), and the number of
cuts and time (seconds) used by the OA algorithm. The OA algorithm was terminated
once the time exceeded 3600s, or the time attempting to generate a cut exceeded 600s,
or the number of cuts exceeded 100.

the COP-OA algorithm is exact on one more instance than the DNN relaxation, it

higher then the DNN gap, with most of these corresponding to larger problems where
the algorithm was terminated after exceeding the 3600s time limit. Another way of
looking at the summary in Table 2 is that of the 16 problems on which the DNN
relaxation is _not_ exact, the COP-OA algorithm is exact on 9. The DNN relaxation is
computationally relatively inexpensive, but as noted in Sect. 1 there is no practical way
to strengthen it when it does not provide the optimal solution.

**6 Conclusion**
 
Inthispaperwehavedescribedanalgorithmfornonconvexquadraticproblemsthatcan
be formulated as completely positive (CPOPT) optimization problems, whose duals
are copositive optimization (COOPT) problems. Our method iteratively strengthens
an outer approximation of the set-copositive cone that incorporates linear constraints
from the original CPOPT problem. We extend a previous MILP-based method for
generating a cut that separates a matrix from the copositive cone to incorporate such
linear constraints. Computational results show that the method is capable of globally
solving small nonconvex problems to optimality, with the computational bottleneck
 
 
Solving nonconvex optimization problems using outer...
 
being the MILP-based separation routine. This observation suggests that modifications
to the separation problem that make it more computationally tractable would be very
beneficial; some possibilites include warm-starting the solution process and/or termi-
nating it early, if a feasible solution with positive objective value is found. In addition,
CPOPT formulations often include linear constraints that combine the original vari-
ables _x_ and lifted matrix variables _X_ ; examples include constraints obtained from the
reformulation–linearization technique (RLT) and constraints of the form _x_ =diag( _X_ )
for binary _x_. An extension of our methodology that could incorporate such constraints
in the separation routine would be an attractive enhancement.
